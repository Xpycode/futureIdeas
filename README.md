# Future Ideas

A collection of product ideas and specs for possible future apps.

| Idea | Platform | Status | One-liner |
|---|---|---|---|
| [QC Checker](ideas/qc-checker/SPEC.md) | macOS (SwiftUI) | Spec draft | Check video files against a delivery spec, including loudness, and get a pass/fail report. |
| [Audio Channel Remapper](ideas/audio-channel-remapper/SPEC.md) | macOS (SwiftUI) | Spec draft | Reroute, reorder, split and merge audio channels in video files, without re-encoding the video. |

Each idea lives in `ideas/<name>/` with a `SPEC.md`.

All macOS apps here ship as direct downloads, signed with Developer ID and notarised. The Mac App Store is not a goal.
